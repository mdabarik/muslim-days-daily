Firebase Crashlytics — MD-004 high-priority analysis

আপনার দেওয়া Oct 19–25 snapshot: release 3.0.3 (30), crash-free users 92.36%, crash-free sessions 97.72%, 128 events, 31 users। এগুলো নতুন dashboard data এলে refresh করতে হবে।

1 · QR barcode module

63 events পর্যন্ত দুই signature-এ। Unbundled Google barcode model first use-এ download হয়। “Waiting for module” expected availability state—fatal নয়। Preparing UI, retry/gallery fallback এবং non-fatal reporting; reliability চাইলে bundled model trade-off review।

2 · Wrong ABI libflutter.so

27 events / 8 users, 1.3.0–3.0.2, session-এর প্রথম 5 seconds। AArch64 library x86_64 process-এ load হয়েছে। Current ARM-only filter, Play split/device catalog, old upgrade ও emulator/ChromeOS path verify করতে হবে।

3 · OpenStreetMap DNS

19 events / 4 users, 3.0.3 পর্যন্ত। Tile DNS/network failure app crash হওয়া উচিত নয়। Tile error/fallback, cache, bounded retry এবং policy-compliant provider দরকার।

4 · Quran API 504/timeout

17 events / 13 users related signatures। `QuranApiException` expected UI error; সব await path catch, cache-first/retry/offline state এবং non-fatal logging দরকার।

5 · Widget ActionTrampoline

2 events / 2 users, older releases। Concrete target intent/deep link, stale widget upgrade এবং affected launcher/Android test দরকার।

Cross-cutting metric fix

`PlatformDispatcher.instance.onError` সব uncaught async error-কে fatal হিসেবে record করছে। Feature boundary-তে expected failures ধরতে হবে; সত্যিকার terminating/corrupting error ছাড়া fatal নয়।

Crash priority: current release-এ affected users অনুযায়ী Quran API এবং OSM robustness; সর্বোচ্চ event volume অনুযায়ী QR module; startup severity অনুযায়ী ABI issue। শুধু event hide নয়—reproduction, fallback এবং fixed-version rollout verification দরকার।
